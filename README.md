# Curso Corsa DHB — Oficina Eficiente

Página baseada no curso Monza, com conteúdo adaptado da transcrição Subtitle 1(2).srt.

## Cloudflare Workers

- `npm ci`
- `npm run build` — valida sem publicar
- `npm run deploy` — publica com credenciais Cloudflare
- Nome do Worker: curso-corsa; assets: public; entrada: src/worker.js

## Conteúdo e pendências comerciais

Escopo: DHB 22 mm, bucha grande/pequena; aplicações citadas: Corsa/Classic, Celta, Prisma, Agile e Montana 2011+. Novo Corsa, Meriva e Montana antiga de 25 mm são diferenciados e não anunciados como cobertos.

Os depoimentos são os mesmos da página Monza e identificados como relatos de outros treinamentos.

Antes de abrir vendas, configurar formulário AtendeIA e checkout ESPECÍFICOS do Corsa, confirmar preço/parcelamento, prazo de acesso, certificado e suporte. O formulário do Monza redireciona à compra do Monza e não foi reutilizado. Os botões abrem um aviso de inscrições em breve, sem coletar dados. Não há preço, duração comercial, garantia ou benefícios não confirmados. A transcrição inclui encerramento e material promocional, portanto o tempo total do SRT não é usado como duração de aulas.
